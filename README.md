# GYEOL STUDIO 템플릿 견본 이미지

이 저장소는 **GYEOL STUDIO 식스샵 템플릿**의 견본 이미지입니다.

- 이미지는 Google Gemini(Nano Banana)로 생성했고, **SynthID 워터마크**가 포함돼 있습니다.
- **독점 사용권이 아닙니다.** 템플릿 구매자는 자신의 실제 작품 사진으로 교체해 사용합니다.
- 식스샵 블록메이커 블록이 이미지를 URL로 불러오기 때문에 공개 저장소로 운영합니다.

## 구조
`images/` 폴더 하나에 45장이 있습니다. 파일명은 원본 그대로입니다.

## 주소 형식
```
https://raw.githubusercontent.com/aewonstudio/gyeol-template-assets/main/images/{파일명}
```
